# Regras do repositório

- Trabalhe apenas na branch atual.
- Ao receber uma tarefa, execute primeiro `git status` e `git branch --show-current`.
- Nunca execute `git commit`, `git push`, `git merge`, `git rebase` ou `git checkout` sem autorização explícita do usuário.
- Antes de alterar código, apresente um resumo do que pretende fazer.
- Nunca altere arquivos `.env`, credenciais ou chaves.
- Peça confirmação antes de instalar novas dependências.
- Mantenha frontend e backend separados e respeite a estrutura atual do projeto.
- Antes de concluir, informe os arquivos modificados e os testes executados.
